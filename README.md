##  Projects

### 1. Student Grade Manager

A simple command-line application built with Python that helps manage student records, search for students and calculate academic grades.

This is one of my beginner projects, developed to practise Python fundamentals and apply what I'm learning in real-world scenarios.

###  Features

The application currently supports:

- *Add Student:** Register students by entering their names and scores.
-  **View Students:** Display all registered students and their academic records.
-  **Search Student:** Find a registered student by name.
-  **Delete Student:** Remove a student record with a confirmation step.
-  **Automatic Grade Calculation:** Calculate grades based on students' scores.
-  **Input Validation:** Handle invalid score entries and unexpected confirmation inputs.

###  Getting Started

To run the project locally:

**1. Clone the repository**

```bash
git clone https://github.com/Java-thecreator/Python-pratice.git
```

**2. Navigate to the project directory**

```bash
cd Python-practice/python_projects/student_grade_manager
```

**3. Run the application**

```bash
python student_grade_manager.py
```

Make sure Python 3 is installed on your computer.
